# Claude sürümü

Bu klasördeki `index.html`, oyunun Claude üzerinde çalışan (artifact) sürümüdür. Oyun kodu uygulamayla aynıdır; online oda, turnuva ve puan durumu Claude'un kendi altyapısını kullanır. Google girişi ve online lig bu sürümde yoktur.

Asıl uygulama (Firebase + Play Store) üst klasördedir: bkz. `../README.md`.
